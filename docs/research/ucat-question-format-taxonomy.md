# UCAT question taxonomy: content categories and response formats

Date: 2026-08-09

## Question

Does UCAT distinguish a question's subject/category from the response interaction used to answer it, and specifically:

- is `Syllogisms` a Decision Making item category rather than the name of the drag-and-drop response type;
- do non-syllogism Decision Making items also use that response type;
- how should the Situational Judgement most/least-appropriate interaction relate to the usual appropriateness and importance categories; and
- does any other current UCAT ANZ subtest use drag and drop?

## Conclusion

Yes. The official taxonomy separates **response type** from **item type**, and Altitutor should preserve that distinction.

The clearest primary evidence is Pearson's 2025 UCAT technical report. It says that Decision Making varies in both "response format" and "item type", then records this exact matrix:

| Response type | Item type |
| --- | --- |
| Drag and Drop | Information Interpretation |
| Drag and Drop | Syllogisms |
| Multiple Choice | Logical Puzzles |
| Multiple Choice | Statistical Reasoning |
| Multiple Choice | Assumptions Recognition |
| Multiple Choice | Venn Diagrams |

([2025 UCAT technical report, pp. 54–55](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf))

This establishes that `Syllogisms` is not the response type. It is one of two current Decision Making item types that use the `Drag and Drop` response type. `Information Interpretation` is the other. The official 2024 report published the same pairing, so this is not a one-year anomaly. ([2024 UCAT technical report, pp. 57–58](https://www.ucat.ac.uk/media/1672/ucat-2024-technical-report-final.pdf))

For Situational Judgement, the official materials distinguish **rating items** from **Most/Least items**. Rating items are further described by content/category as appropriateness (including speech/direct-speech variants) or importance. A Most/Least item asks for the most and least appropriate actions from three actions; the official evidence does not identify a corresponding "most/least important" format. Therefore, if Altitutor's SJT categories are intended to track official item types, the source-backed addition is one category such as `Most/Least Appropriate`, not two new drag-and-drop categories and not silently folding these items into either of the standard four-point rating categories. ([2025 UCAT technical report, pp. 59–62](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf), [official 2018 question tutorial](https://www.ucat.ac.uk/uploads/ukcat-tutorials/2018/story_html5.html), [UCAT ANZ Official Guide 2020, pp. 18–19](https://www.ucat.edu.au/media/1332/ucat-official-guide-2020.pdf))

The current UCAT ANZ site says that drag-and-drop questions occur in **Decision Making and Situational Judgement**. Its current test format contains four subtests: Verbal Reasoning, Decision Making, Quantitative Reasoning and Situational Judgement. This supports the bounded conclusion that only DM and SJT need a candidate-facing drag-and-drop response renderer in the current UCAT ANZ taxonomy; the official source does not identify drag-and-drop items in VR or QR. ([UCAT ANZ test tools](https://www.ucat.edu.au/prepare/test-tools/), [UCAT ANZ test format](https://www.ucat.edu.au/about-ucat-anz/test-format/))

## Decision Making in detail

### Syllogisms and information interpretation share an interaction, not a category

The 2025 technical report explicitly calls `Drag and Drop` the **response type** and `Information Interpretation` / `Syllogisms` the **item types**. It separately calls the other four item types `Multiple Choice`. ([2025 UCAT technical report, pp. 54–55](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf))

The current public UCAT ANZ format page describes the same response shape without assigning it to syllogisms: some DM questions are multiple choice, while others require responses to five statements by placing a Yes or No beside each statement. ([UCAT ANZ test format](https://www.ucat.edu.au/about-ucat-anz/test-format/))

The older official interactive tutorial provides the useful content distinction that the present high-level pages omit:

- syllogism items ask whether each conclusion follows from a set of premises and call attention to quantifiers such as all, some, none and only;
- information-interpretation items present information in formats including written passages, graphs and charts and ask which conclusions follow;
- both require the candidate to drag the correct responses to the conclusions.

([official 2018 question tutorial](https://www.ucat.ac.uk/uploads/ukcat-tutorials/2018/story_html5.html))

This confirms the user's recollection: Information Interpretation is not merely a loose synonym for syllogism. It can use a passage, graph, chart or other information presentation, while still sharing the same five-statement Yes/No drag-and-drop response interaction.

### Pearson bank-analysis taxonomy

For a data mapping that mirrors Pearson's current bank-analysis labels, use:

| Category / item type | Response type |
| --- | --- |
| Information Interpretation | Drag and Drop |
| Syllogisms | Drag and Drop |
| Logical Puzzles | Multiple Choice |
| Statistical Reasoning | Multiple Choice |
| Assumptions Recognition | Multiple Choice |
| Venn Diagrams | Multiple Choice |

These are Pearson's psychometric bank-analysis labels. They are not all the same as the current candidate-facing UCAT ANZ tutorial labels. They remain useful stable aliases for comparing technical reports, but should not override the live tutorial vocabulary in an exam-simulation product. ([2025 UCAT technical report, pp. 54–55](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf), [current UCAT ANZ question tutorials](https://www.ucat.edu.au/prepare/question-tutorials/))

### Evaluating Arguments versus Assumptions Recognition

`Evaluating Arguments` and `Assumptions Recognition` are not two coequal current item types, and the available official evidence does not show one replacing the other.

The 2016 Decision Making trial described three broad **constructs**, each containing two more specific forms:

| 2016 construct | More specific forms named under it |
| --- | --- |
| Deductive Reasoning | Syllogisms; Logical Puzzles |
| Evaluating Arguments | Recognising Assumptions; Interpreting Information & Drawing Conclusions |
| Statistical and Figural Reasoning | Venn Diagrams; Probabilistic & Statistical Reasoning |

([UKCAT Annual Report 2016/17, p. 14](https://www.ucat.ac.uk/media/1199/annual-report-2016-2017.pdf))

This makes `Evaluating Arguments` an umbrella construct in the original design, not an additional seventh item category. It covered both the strongest-argument/assumption material and the information-interpretation/drawing-conclusions material.

The official 2017 and 2018 tutorials used the candidate-facing description "evaluate arguments" for questions that ask the candidate to select the strongest argument, while their overview said candidates would see questions requiring them to "recognise assumptions". Those are two descriptions of the same strongest-argument family in that tutorial, not evidence of two separate multiple-choice item formats. ([official 2017 tutorial](https://www.ucat.ac.uk/uploads/ukcat-tutorials/2017/story_html5.html), [official 2018 tutorial](https://www.ucat.ac.uk/uploads/ukcat-tutorials/2018/story_html5.html))

The current Pearson bank-analysis label is `Assumptions Recognition`. It is the only one of those two labels appearing as the multiple-choice item type in the 2022, 2023, 2024 and 2025 technical-report tables. `Evaluating Arguments` does not appear as a separate current item type in those tables. ([2022 report, pp. 43–45](https://www.ucat.ac.uk/media/1546/ucat-2022-technical-report.pdf), [2023 report, pp. 44–46](https://www.ucat.ac.uk/media/1581/ucat-2023-technical-report.pdf), [2024 report, DM item-analysis section](https://www.ucat.ac.uk/media/1672/ucat-2024-technical-report-final.pdf), [2025 report, pp. 54–55](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf))

Therefore, when reading technical reports:

- read `Assumptions Recognition` as the exact current Pearson bank-analysis name;
- read the UCAT ANZ tutorial's `Recognising Assumptions` as the candidate-facing name for that same item family;
- do not add `Evaluating Arguments` as another current category; and
- do not blindly migrate a historical record labelled only `Evaluating Arguments` to `Assumptions Recognition`, because the original umbrella also included what is now `Information Interpretation`. Inspect the item's response shape and prompt: a four-option strongest-argument question maps to `Assumptions Recognition`, while a five-statement conclusion task based on presented information maps to `Information Interpretation`.

### Canonical 2026 UCAT ANZ product taxonomy and Altitutor mapping

No 2026 administration technical report can exist before the 2026 testing data are analysed. The most current detailed primary source is therefore Pearson's 2025 technical report, published by UCAT in 2026, read alongside the live 2026 UCAT ANZ format and tools pages. The 2025 report directly compares the 2025 UCAT and UCAT ANZ operational item statistics and reports a shared DM item analysis; none of these official sources identifies a UK-versus-ANZ difference in DM item types. ([2025 UCAT technical report, pp. 56–58](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf), [current UCAT ANZ test format](https://www.ucat.edu.au/about-ucat-anz/test-format/), [current UCAT ANZ test tools](https://www.ucat.edu.au/prepare/test-tools/))

The live UCAT ANZ Decision Making tutorial presents this exact candidate-facing taxonomy:

1. `Syllogisms`
2. `Logical Puzzles`
3. `Recognising Assumptions`
4. `Interpreting Information and Drawing Conclusions`
5. `Venn Diagrams`
6. `Probabilistic and Statistical Reasoning`

([current UCAT ANZ question tutorials](https://www.ucat.edu.au/prepare/question-tutorials/), [current official Decision Making tutorial](https://www.canva.com/design/DAHDALnhQkg/1JstNQq3Og2ZtUnslP4Auw/view))

For a product whose goal is to simulate the candidate experience, these tutorial labels should be canonical. Pearson's shorter technical-report labels are aliases for bank analysis, not preferable UI replacements:

| Candidate-facing UCAT ANZ category | Pearson bank-analysis alias | Response type | Altitutor's current seeded category | Recommended migration |
| --- | --- | --- | --- | --- |
| Interpreting Information and Drawing Conclusions | Information Interpretation | Drag and Drop | Missing; historical `Drawing Conclusions` was removed and reassigned to `Syllogisms` | Add the full candidate-facing category name. Reclassify legacy Drawing Conclusions/content-based Yes/No items here when they interpret a passage, chart, table, graph or similar evidence rather than quantified syllogistic premises. |
| Syllogisms | Syllogisms | Drag and Drop | `Syllogisms` | Keep the category; stop using it as the response/UI type. |
| Logical Puzzles | Logical Puzzles | Multiple Choice | `Logical Puzzles` | Keep unchanged. |
| Probabilistic and Statistical Reasoning | Statistical Reasoning | Multiple Choice | `Probabilistic and Statistical Reasoning` | Keep the candidate-facing Altitutor name unchanged; treat `Statistical Reasoning` as its Pearson reporting alias. |
| Recognising Assumptions | Assumptions Recognition | Multiple Choice | `Recognising Assumptions` | Keep the candidate-facing Altitutor name unchanged; treat `Assumptions Recognition` as its Pearson reporting alias. Do not create a separate `Evaluating Arguments` category. |
| Venn Diagrams | Venn Diagrams | Multiple Choice | `Venn Diagrams` | Keep unchanged. |

Altitutor's seeded names come from the UCAT section/category migration, and the later migration explicitly reassigned the removed `Drawing Conclusions` category to `Syllogisms`. ([category seed](../../supabase/migrations/20260316150000_seed_ucat_sections.sql), [`Drawing Conclusions` removal](../../supabase/migrations/20260622140005_remove_drawing_conclusions_category.sql), [current category descriptions](../../supabase/migrations/20260708082351_improve_ucat_taxonomy_descriptions.sql))

That reassignment is too broad in light of the official taxonomy. `Drawing Conclusions` is part of the current candidate-facing `Interpreting Information and Drawing Conclusions` category and was historically paired the same way; it is not simply another name for syllogisms. The content of each already-reassigned stem should be audited rather than moved en masse a second time. ([current official Decision Making tutorial](https://www.canva.com/design/DAHDALnhQkg/1JstNQq3Og2ZtUnslP4Auw/view), [UKCAT Annual Report 2016/17, p. 14](https://www.ucat.ac.uk/media/1199/annual-report-2016-2017.pdf), [2025 UCAT technical report, pp. 54–55](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf))

## Situational Judgement in detail

### The official response families

The 2025 technical report analyses two SJT response families:

1. **Rating items**, categorised as appropriateness, appropriateness involving speech/direct speech, or importance.
2. **Most/Least items**, analysed separately from the rating items.

For new 2025 pilot items, the report says the former labels `Appropriateness` and `Direct Speech` were updated to `Appropriateness` and `Appropriateness (Speech)` and grouped into one category for its table. That is a year-specific label refinement, not evidence for a new response interaction. ([2025 UCAT technical report, pp. 59–62](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf))

The official tutorial explains the semantic difference:

- rating items independently rate an action's appropriateness or a consideration's importance on a four-point scale;
- Most/Least items choose the most appropriate and least appropriate actions from three actions, prioritising them relative to one another.

The Most/Least format is drag and drop in the official tutorial. ([official 2018 question tutorial](https://www.ucat.ac.uk/uploads/ukcat-tutorials/2018/story_html5.html))

The attached example matches the second family exactly: three actions feed two destinations labelled `Most Appropriate` and `Least Appropriate`. It is not a four-point `How Appropriate?` rating item and it is not an importance item.

### Category recommendation supported by the sources

If Altitutor wants categories to express the assessed item family, use one distinct SJT category such as `Most/Least Appropriate` (or the shorter official-style `Most/Least`) alongside the rating categories. Do not make two categories merely because there are two drop targets: "most" and "least" are the two required answers within one item, not separate question categories.

It would also be reasonable to model SJT along two semantic axes in the future—for example, `judgement_dimension = appropriateness | importance` and `response_type = rating | drag_and_drop`—but the current official evidence only demonstrates the drag-and-drop format for choosing most/least **appropriate actions**. It does not establish a `most/least important` counterpart. Creating that counterpart would therefore be an Altitutor invention, not a migration of the UCAT taxonomy.

### SJT structural cardinalities and publication gates

The current UCAT ANZ test-format page says that each SJT scenario may have **up to six questions** associated with it. It does not publish a minimum and does not say that every scenario has exactly four, five or six questions. ([current UCAT ANZ test format](https://www.ucat.edu.au/about-ucat-anz/test-format/))

For the standard rating family, each associated question/action or consideration is judged independently on one four-point scale. The official tutorial demonstrates four appropriateness responses and four importance considerations, but tutorial examples are illustrative and the current format page's only explicit general cardinality is the maximum of six. ([current UCAT ANZ question tutorials](https://www.ucat.edu.au/prepare/question-tutorials/), [official 2018 question tutorial](https://www.ucat.ac.uk/uploads/ukcat-tutorials/2018/story_html5.html))

That supports these authoring gates for `How Appropriate` and `How Important`:

- hard publication gate: no more than six independently rated items may share one scenario;
- ordinary data-integrity gate: at least one associated item must exist;
- do **not** hard-require exactly four items merely because the tutorial example contains four; and
- do **not** claim an official minimum greater than one from the current public source.

Historically, the UCAT ANZ 2019 and 2020 guides described 69 SJT questions associated with 22 scenarios, with **between two and five questions per scenario**. The current public wording has changed to "up to six" and omits the old minimum. A 2026 product should use the current upper bound and should not preserve `2–5` as a hard current rule. ([UCAT ANZ Official Guide 2019, pp. 18–19](https://www.ucat.edu.au/media/1298/ucat-official-guide-2019.pdf), [UCAT ANZ Official Guide 2020, pp. 18–19](https://www.ucat.edu.au/media/1332/ucat-official-guide-2020.pdf), [current UCAT ANZ test format](https://www.ucat.edu.au/about-ucat-anz/test-format/))

For the Most/Least family, official tutorial wording defines one combined item that requires the candidate to choose:

- one `Most Appropriate` action;
- one `Least Appropriate` action;
- from exactly three provided actions.

Both destinations belong to that one response item; they are not two separately categorised questions. The two selected actions must be distinct because one action is placed in each of the two roles from the same three-action pool. ([current official UCAT ANZ Situational Judgement tutorial](https://www.canva.com/design/DAHDFszTb68/h-6CaeAxwETfB_9m0JO02g/view), [official 2018 question tutorial](https://www.ucat.ac.uk/uploads/ukcat-tutorials/2018/story_html5.html))

This supports hard publication gates of exactly three source actions, exactly two destinations (`Most Appropriate`, `Least Appropriate`), exactly one action per destination, no action reused across both destinations, and both destinations required for a complete response. Pearson's 2022 technical report independently treats a response containing only one of the two placements as incomplete. ([2022 UCAT technical report, pp. 47–48](https://www.ucat.ac.uk/media/1546/ucat-2022-technical-report.pdf))

The reviewed public sources do **not** establish that a scenario containing a Most/Least item must contain no other associated SJT items. The hard gate should apply to the Most/Least response unit, not assume that the surrounding scenario is structurally exclusive unless the live content bank or an additional official specification proves that rule.

### Published full-test counts versus item-analysis counts

The official sources use several different counting units. They must not be collapsed into one product field:

- a **scenario** or **testlet** is shared stimulus material;
- a **question/item** is one numbered response task associated with that material;
- a **Most/Least item** is one question even though its response contains two required placements;
- an **operational/scored item** contributes to the candidate's score; and
- a **pretest/unscored item** is embedded in the delivered test to evaluate it for possible future use.

The current UCAT ANZ candidate-facing totals are **35 Decision Making questions** and **69 SJT questions**. The live ANZ page additionally says each SJT scenario may have up to six associated questions, but it does not publish a current scenario count or a split of the 69 questions by rating versus Most/Least format. ([current UCAT ANZ test format](https://www.ucat.edu.au/about-ucat-anz/test-format/), [current UCAT ANZ scoring](https://www.ucat.edu.au/about-ucat-anz/scoring/))

The live 2026 standard-test table publishes the complete subtest totals and timings as follows:

| Subtest | Questions | Timed instruction section | Answering time |
| --- | ---: | ---: | ---: |
| Verbal Reasoning | 44 | 1 minute 30 seconds | 22 minutes |
| Decision Making | 35 | 1 minute 30 seconds | 37 minutes |
| Quantitative Reasoning | 36 | 2 minutes | 26 minutes |
| Situational Judgement | 69 | 1 minute 30 seconds | 26 minutes |

The minutes in the `Test Time`/standard-timing column are answering time and do **not** include the separately timed instruction section that precedes each subtest. The four answering periods total 111 minutes; the instruction periods total 6 minutes 30 seconds, producing the official standard-test duration of 117 minutes 30 seconds. An authoring or exam-runtime model should therefore store instruction time separately rather than folding it into the subtest answering timer. ([current UCAT ANZ test format](https://www.ucat.edu.au/about-ucat-anz/test-format/), [current UCAT ANZ extended-tests page](https://www.ucat.edu.au/about-ucat-anz/test-format/extended-tests/))

The latest Pearson report supplies more detailed **UCAT 2025** exam-design data, which should not be silently relabelled as a 2026 UCAT ANZ specification. It records five balanced UCAT forms. Each DM form contained 31 scored items and four unscored items, for the same candidate-visible total of 35. For SJT it records 20 scored testlets containing one to four items and two unscored testlets containing one to five items, with 69 items overall. This establishes a 22-testlet design for that UCAT 2025 administration, but the report does not say that every testlet had the same item count and the live UCAT ANZ page now allows up to six questions per scenario. ([2025 UCAT technical report, exam design and test-form analysis, pp. 10–11 and 46–47](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf))

Pearson's item-analysis tables count items **across the operational and pretest pools analysed**, rather than publishing a promised category quota for a future candidate's form:

| 2025 analysis population | Published analysed-item counts |
| --- | --- |
| DM operational/scored | 155 total: 25 Information Interpretation, 30 Syllogisms, 25 Logical Puzzles, 20 Statistical Reasoning, 20 Assumptions Recognition, 35 Venn Diagrams |
| DM pretest/unscored | 238 total: 49 Information Interpretation, 48 Syllogisms, 32 Logical Puzzles, 40 Statistical Reasoning, 19 Assumptions Recognition, 50 Venn Diagrams |
| SJT operational/scored | 198 rating items and 9 Most/Least items |
| SJT pretest/unscored | 353 rating items and 18 Most/Least items |

([2025 UCAT technical report, Tables 45, 48 and 55, pp. 52–54 and 58–59](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf))

For DM, the 155 operational count equals five forms multiplied by 31 scored items, and every category total happens to be divisible by five. It is therefore *consistent with* each balanced form containing 5 Information Interpretation, 6 Syllogisms, 5 Logical Puzzles, 4 Statistical Reasoning, 4 Assumptions Recognition and 7 Venn Diagram items. However, the reviewed report does not explicitly publish that per-form allocation or promise it for UCAT ANZ 2026. The division is an inference, not a safe hard publication rule.

For SJT, the `9` operational Most/Least items in Table 55 emphatically does **not** mean nine Most/Least questions appeared on every candidate's test. The same report has five candidate forms, and its item-analysis section describes the statistics as analysis of operational and pretest items administered during the testing window. It does not provide a Most/Least count for each form or a minimum/maximum across forms. Item reuse and allocation across forms are not exposed in that table. Accordingly, no fixed current number or official range of SJT Most/Least items per full UCAT ANZ test can be justified from the public primary sources reviewed.

Historical technical reports reinforce the distinction rather than filling the gap: Pearson reported aggregate operational Most/Least analysis counts of 5 in 2021, 6 in 2023, and 9 in 2024 and 2025. Those are year-specific analysed operational pools, not published per-candidate form specifications. ([2021 UCAT technical report, SJT item analysis](https://www.ucat.ac.uk/media/1508/ucat-2021-technical-report.pdf), [2023 UCAT technical report, SJT item analysis](https://www.ucat.ac.uk/media/1581/ucat-2023-technical-report.pdf), [2024 UCAT technical report, SJT item analysis](https://www.ucat.ac.uk/media/1672/ucat-2024-technical-report-final.pdf), [2025 UCAT technical report, SJT item analysis](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf))

The official UCAT ANZ practice tests and question banks are described as representative of the live test, while the tutorials say their examples do not cover every aspect. Neither statement publishes a fixed category composition. Counting examples in a tutorial, question bank or one practice form would at most describe that sample; it would not establish an operational quota or range. ([current UCAT ANZ practice tests and question banks](https://www.ucat.edu.au/prepare/practice-tests/), [current UCAT ANZ question tutorials](https://www.ucat.edu.au/prepare/question-tutorials/))

For authoring and assembly, the source-backed gates are therefore:

- a full 2026 UCAT ANZ simulation contains 35 DM questions and 69 SJT questions;
- an SJT scenario contains no more than six associated questions;
- a Most/Least question remains one response item with two placements, not two questions; and
- do not hard-code DM category quotas, an exact SJT scenario count, or a fixed/ranged number of SJT Most/Least questions as an official 2026 rule. If Altitutor chooses such assembly targets for pedagogical balance, label them as product policy and keep them configurable.

## Current versus historical evidence

- The present UCAT ANZ test-tools page explicitly says some DM and SJT questions require drag and drop. ([UCAT ANZ test tools](https://www.ucat.edu.au/prepare/test-tools/))
- A UCAT ANZ accessibility document issued for the 2026 exam independently discusses drag-and-drop items in both DM and SJT. It says SJT "now includes" such items, but does not mean they were first introduced in 2026: official guides/tutorials document SJT most/least drag-and-drop items at least as far back as 2018, and UCAT ANZ's 2019 and 2020 guides describe the most/least item family. ([2026 UCAT ANZ colour-scheme and font-size guidance, pp. 1–3](https://www.ucat.edu.au/media/1583/ucat-anz-access-arrangements_colour-scheme-and-font-size_2026.pdf), [official 2018 question tutorial](https://www.ucat.ac.uk/uploads/ukcat-tutorials/2018/story_html5.html), [UCAT ANZ Official Guide 2019, pp. 18–19](https://www.ucat.edu.au/media/1298/ucat-official-guide-2019.pdf))
- Pearson's 2024 and 2025 technical reports both record `Information Interpretation` and `Syllogisms` under the DM `Drag and Drop` response type. ([2024 report](https://www.ucat.ac.uk/media/1672/ucat-2024-technical-report-final.pdf), [2025 report](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf))
- Abstract Reasoning is no longer present in the current 2026 UCAT ANZ four-subtest format. Historical pages that list it should not drive the target model. ([current UCAT ANZ test format](https://www.ucat.edu.au/about-ucat-anz/test-format/))

## Implications for an Altitutor migration

The source-backed target concept is:

```text
section/subtest
  -> category/item type (what is assessed and how the stimulus is structured)
  -> response type (which answer interaction, validation shape and renderer apply)
```

In particular:

```text
Decision Making / Syllogisms                 -> Drag and Drop
Decision Making / Interpreting Information and Drawing Conclusions -> Drag and Drop
Situational Judgement / Most/Least Appropriate -> Drag and Drop
```

`Drag and Drop` is a useful public/domain name for the official response type. Internally, a more structural name such as `multi_statement_binary` would be narrower for DM, because DM's five Yes/No destinations and SJT's two ranked destinations do not have the same answer schema even though both use dragging. If the enum is expected to choose one renderer and one persistence/marking contract, a single undifferentiated `drag_and_drop` value may need a subtype or response configuration. The official taxonomy proves the UI family is shared; it does **not** prove that the answer payloads are identical.

This last point is an architectural inference from the documented interactions, not an official UCAT term.

## Official drag-and-drop interaction mechanics

For the live UCAT ANZ exam, drag and drop means literal pointer dragging:

- the candidate must use the mouse for a question requiring a dragged answer;
- the candidate clicks and holds a response, drags it, and drops it into the relevant destination box;
- replacing an answer requires dragging a different response over the destination; and
- removing an answer requires dragging it away from the destination.

The same official page says keyboard shortcuts can select ordinary lettered answer responses but explicitly excludes drag-and-drop questions from that keyboard-selection path. It does not document click-a-source-then-click-a-destination, tap-to-place, keyboard placement, or a non-drag fallback. ([current UCAT ANZ test tools](https://www.ucat.edu.au/prepare/test-tools/))

The live exam is delivered at a workstation with a PC, monitor, keyboard and mouse, so the official instructions do not define touch behaviour. A tap/click-to-place alternative could be a useful Altitutor accessibility or mobile-practice enhancement, but it would be an added product interaction rather than a faithful reproduction of the documented test mechanic. If exam-fidelity mode is meant to teach the real interaction, it should require pointer drag and drop.

The 2026 UCAT ANZ colour/font accommodation guidance reinforces that these are genuine drag interactions: it warns that magnification above 125% can make DM and SJT drag-and-drop items problematic and says the relevant functionality cannot be replicated in those static practice-material examples. ([2026 UCAT ANZ colour-scheme and font-size guidance, pp. 1–3](https://www.ucat.edu.au/media/1583/ucat-anz-access-arrangements_colour-scheme-and-font-size_2026.pdf))

## Marking contracts

### Decision Making drag-and-drop items

The current UCAT ANZ scoring page gives the public marking contract for Decision Making response families:

- a single-answer question is worth 1 raw mark;
- a multiple-statement question is worth 2 raw marks; and
- a partially correct response to a multiple-statement question receives 1 raw mark.

Those raw marks are then converted into the reported 300–900 Decision Making scale score. The scale conversion is a score-report transformation, not the per-item marking rule. ([current UCAT ANZ scoring](https://www.ucat.edu.au/about-ucat-anz/scoring/))

Pearson's current technical taxonomy establishes that both `Syllogisms` and `Information Interpretation` are the drag-and-drop item types, and says DM drag-and-drop items are scored out of two. Read with the current format page, which describes the non-single-answer format as responding Yes or No to five statements, this supports the same `0 | 1 | 2` stem-level raw-mark contract for both categories. ([2025 UCAT technical report, pp. 53–55](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf), [current UCAT ANZ test format](https://www.ucat.edu.au/about-ucat-anz/test-format/))

The current official public pages do **not** define what count or pattern among the five statement judgements qualifies as "partially correct". In particular, they do not state whether 1 mark means exactly three correct, three or four correct, four correct only, or another rule. Therefore a precise threshold such as `5 correct = 2; 3–4 correct = 1; 0–2 correct = 0` must be treated as an unverified implementation assumption unless Pearson/UCAT supplies a more detailed current scoring specification. It should not be presented as a fact established by the cited public sources.

| DM category | Official maximum raw marks | Official partial credit | Threshold publicly specified? |
| --- | ---: | --- | --- |
| Syllogisms | 2 per five-statement item | 1 mark for a partially correct response | No |
| Interpreting Information and Drawing Conclusions (`Information Interpretation` in Pearson reports) | 2 per five-statement item | 1 mark for a partially correct response | No |

### Situational Judgement Most/Least items

The current UCAT ANZ public scoring page says that an SJT question receives full marks when the response matches the correct answer and partial marks when it is "close" to the correct answer. It does not publish a Most/Least-specific raw-mark table, the maximum raw marks for that format, or what combinations count as close. UCAT ANZ now reports SJT on a 300–900 scale; the UK reports an SJT band. Those are different reporting methods and do not by themselves define the underlying per-item marking matrix. ([current UCAT ANZ scoring](https://www.ucat.edu.au/about-ucat-anz/scoring/), [current UK UCAT format and scoring](https://www.ucat.ac.uk/about-ucat/test-format-and-scoring/))

Pearson's technical reports provide evidence that Most/Least items use a different raw range from standard rating items, but stop short of publishing the scoring lookup. In the 2023 pretest summary, Most/Least items had a mean item score of `7.19` and mean facility of `0.90`; in the 2025 table the corresponding figures were `7.20` and `0.90`. Since facility is defined as mean score divided by the maximum score available, these paired statistics imply a maximum of approximately `8` raw points per complete Most/Least item. That is a strong mathematical inference from Pearson's tables, not an explicitly stated candidate-facing contract. ([2023 UCAT technical report, pp. 50–53](https://www.ucat.ac.uk/media/1581/ucat-2023-technical-report.pdf), [2025 UCAT technical report, pp. 58–62](https://www.ucat.ac.uk/media/1726/ucat-2025-technical-report-final.pdf))

The 2022 technical report also identified responses with only one of the two Most/Least selections as "incomplete" and excluded those candidates under an item-analysis cleaning rule. That proves a complete response requires both selections, but it does **not** establish that an incomplete response earns zero raw marks in the live scoring system. ([2022 UCAT technical report, pp. 47–48](https://www.ucat.ac.uk/media/1546/ucat-2022-technical-report.pdf))

The defensible SJT contract is therefore:

| Claim | Evidence status |
| --- | --- |
| Candidate must select both most and least appropriate actions | Explicit official format; corroborated by Pearson treating a one-selection response as incomplete |
| Exact answer receives full marks; close answer can receive partial marks | Explicit current public scoring guidance |
| Nominal maximum is 8 raw points for a complete Most/Least item | Strong inference from Pearson's item-mean/facility tables |
| Exact points for one correct destination, reversed selections, or selecting the middle-ranked action | Not specified in the current public primary sources reviewed |
| An item with only one destination completed receives zero | Not established; incompleteness and raw score are separate questions |

Until an official marking lookup is obtained, Altitutor should keep the SJT Most/Least marking policy configurable and document any chosen matrix as a product approximation rather than official UCAT scoring.

## Ambiguities and limits

1. The live 2026 UCAT ANZ tutorials are embedded Canva presentations. The candidate-facing category names recorded above come from the live official Decision Making tutorial; Pearson's latest public technical report uses shorter bank-analysis labels for three of those same families.
2. The 2025 technical report is published by the UCAT Consortium/Pearson for UCAT and explicitly compares the shared item-bank statistics with UCAT ANZ 2025. The current UCAT ANZ public format is consistent with it, but UCAT ANZ does not expose an equally detailed public 2026 item-type table.
3. Official materials call the SJT non-rating family `Most/Least items`; `Most/Least Appropriate` is a recommended clearer Altitutor category label, not a quoted official enum value.
4. "Drag and drop" specifies an interaction family, not a complete answer data model. DM information-interpretation/syllogism items assign Yes/No to five statements; SJT Most/Least items select two distinct actions from three. Persistence, marking and accessibility rules must retain those structural differences.
5. Current public UCAT sources disclose the DM multiple-statement `0 | 1 | 2` mark range but not the correctness threshold for the middle mark. They disclose partial credit for SJT generally but not the Most/Least lookup table. Exact marking implementations beyond those boundaries remain uncertain.
6. Official UCAT ANZ instructions require mouse dragging in the live exam and publish no click/tap-to-place fallback. This does not prohibit Altitutor from adding an accessible alternative; it means that alternative should not be described as the documented live-test interaction.
