# Sections

**What this page is for:** Manage UCAT section metadata used across questions, sets, learning modules, and student progress.

**Route:** `/ucat/sections`

---

## Page layout

- Table of sections: number, name, display columns, timing, question counts.
- Filters for column layout and timing fields.
- Header action: **Add Section**.

`[Screenshot: UCAT Sections table with Add Section]`

---

## Add or edit a section

1. Click **Add Section** or row **Edit**.
2. Configure fields such as:
   - Section number and **name**
   - Display columns
   - Instructions (rich text) and instructions time limit
   - Time limit / questions / time per question
3. Save.

`[Screenshot: Edit Section dialog]`

---

## Tips

- Changing timing or question counts affects Reconciliation expectations for sets.
- Keep section names aligned with what students see in the UCAT app.
- Only add new sections when the product actually needs a new exam section — this is foundational config, not day-to-day content work.
