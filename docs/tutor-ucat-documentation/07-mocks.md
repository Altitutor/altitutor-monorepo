# Mocks

**What this page is for:** Assemble full UCAT mock exams from ordered sets.

**Route:** `/ucat/mocks`

---

## Page layout

- Table of mocks (name, visibility, sets, updated).
- Filter by **Visibility**.
- Header action: **Add Mock**.

`[Screenshot: UCAT Mocks table with Add Mock]`

---

## Create a mock

1. Click **Add Mock**.
2. Enter **name**, **visibility**, and optional **instructions** (rich text).
3. Create, then open the editor to attach sets.

`[Screenshot: Create Mock dialog]`

---

## Edit a mock

- Open **Edit** or `/ucat/mocks/[id]`.
- Update name, visibility, and instructions.
- Add sets from the picker, reorder them, remove as needed.
- Watch for visibility warnings (e.g. private sets inside a public mock).
- Save when done.

`[Screenshot: Mock editor with ordered set list]`

---

## Tips

- Order sets to mirror a real mock (section order / timing).
- Prefer publishing sets before making the mock Public.
- Use Reconciliation → Mocks to catch incomplete mock structures.
