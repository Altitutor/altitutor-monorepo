# Students

**What this page is for:** View UCAT student progress across questions, sets, and mocks.

**Route:** `/ucat/students`

---

## Page layout

- Progress summary table for all UCAT students.
- Search: **Search students**.
- Filter by **Class**.
- Progress mode:
  - **All time**
  - **Weighted average**
  - **Time frame** (pick a day range)

`[Screenshot: UCAT Students table with progress mode and class filter]`

---

## What the columns show

- Attempt counts: questions, sets, mocks
- Per-section scores
- Average exam score
- Last attempted

Click **View** on a row to open that student’s progress.

---

## Student progress detail

**Route:** `/ucat/students/[id]`

- Section cards and attempt summaries
- Charts / breakdowns for recent performance
- Drill into:
  - A **section** → category breakdown and set attempts
  - **Mock progress** → list of mocks → a specific mock attempt
  - A **set attempt** → per-question analysis

`[Screenshot: Student progress page with section cards]`

---

## Tips

- Use **Class** filter when reviewing a cohort.
- Switch to **Time frame** for recent improvement rather than lifetime averages.
- Open set/mock attempt detail when a student’s score looks unexpected.
