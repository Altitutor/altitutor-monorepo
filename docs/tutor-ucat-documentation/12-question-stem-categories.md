# Question stem categories

**What this page is for:** Manage section-scoped categories for UCAT question stems (passages / shared stimulus).

**Route:** `/ucat/question-stem-categories`

---

## Page layout

- Category tree grouped by **section**.
- Header action: **Add Category**.
- Linked stems can be opened from a category.

`[Screenshot: Question Stem Categories tree by section]`

---

## Add a category

1. Click **Add Category**.
2. Enter:
   - **Section** (required)
   - **Name**
   - Optional **Parent category**
   - Optional **Description**
3. Save.

---

## Edit, move, delete

- Edit a category to rename or change parent/description.
- Drag to reparent within the section hierarchy.
- Delete carefully — stems using that category will need reassignment.

`[Screenshot: Add Category dialog]`

---

## Tips

- Categories power filters, set auto-selection, and Reconciliation checks.
- Keep one clear taxonomy per section; avoid deep nesting unless needed.
- Aim for every live stem to have a category (Reconciliation will flag gaps).
