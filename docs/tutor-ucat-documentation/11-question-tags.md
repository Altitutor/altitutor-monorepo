# Question tags

**What this page is for:** Manage hierarchical tags used to classify individual UCAT questions.

**Route:** `/ucat/question-tags`

---

## Page layout

- Tag tree (can be scoped under sections).
- Search the tree to find a tag quickly.
- Header action: **Add Tag**.

`[Screenshot: Question Tags tree with Add Tag]`

---

## Add a tag

1. Click **Add Tag**.
2. Enter:
   - **Name**
   - Optional **Parent tag**
   - Optional **Section**
   - Optional **Description**
3. Save.

---

## Edit, move, delete

- Open a tag to edit name/description/parent.
- Drag tags to reparent / reorder in the hierarchy.
- Delete only when you’re sure nothing important still relies on that tag (linked questions can be opened from the tag).

`[Screenshot: Edit tag dialog or drag-reparent tree]`

---

## Tips

- Prefer a shallow, consistent hierarchy per section.
- Use tags for skills/topics; use **stem categories** for passage-level grouping.
- Keep names short so filters on the Questions page stay readable.
