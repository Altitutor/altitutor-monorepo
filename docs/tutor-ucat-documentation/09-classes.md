# Classes

**What this page is for:** View UCAT class rosters and assign content (sets, mocks, stems, lessons) to class sessions.

**Route:** `/ucat/classes`

---

## Page layout

- Table of classes: time, students, staff.
- Search: **Search classes**.
- Row action: **Edit** → class sessions dialog.

`[Screenshot: UCAT Classes table]`

---

## Assign content to sessions

1. Click **Edit** on a class.
2. In **Edit class sessions**:
   - **Left:** sessions (by date) — search / filter / sort as needed
   - **Right:** resource tabs — **Sets**, **Mocks**, **Stems**, **Lessons**
3. Drag resources from the catalog onto a session.
4. Reorder or remove items within a session.
5. **Save** when done.

`[Screenshot: Edit class sessions dialog with Sets tab and session drop targets]`

---

## Tips

- Assign content before the session so students see the right work on the day.
- Prefer sets/mocks over one-off stems when the goal is timed practice.
- Lessons come from Learning modules — keep titles clear so the catalog is easy to scan.
