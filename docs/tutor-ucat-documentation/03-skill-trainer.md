# Skill trainer

**What this page is for:** Author and manage skill-trainer drill items used in the UCAT app (separate from the main question bank).

**Route:** `/ucat/skill-trainer-questions`

---

## Page layout

- Each **tab** is a trainer type (e.g. different drill formats).
- The table lists items for the selected type.
- Filters:
  - **Approval** — Approved / Pending / Rejected
  - **Active** — Active / Inactive

`[Screenshot: Skill trainer page with type tabs and filters]`

---

## Add a question

1. Select the correct trainer-type tab.
2. Click **Add question**.
3. Fill in the content for that trainer format.
4. Set approval / active status as needed.
5. Save.

`[Screenshot: New skill trainer question dialog]`

---

## Edit or bulk-update

- **Edit** a row to change content or status.
- Select multiple rows to bulk-update **approval** or **delete**.
- Use filters to focus on pending or inactive items before publishing.

---

## Tips

- Keep skill-trainer items short and focused — they’re drills, not full stems.
- Approve only when the item is ready for students.
- Inactive items stay in the bank but aren’t offered in the student app.
