# UCAT overview

**What this page is for:** Hub for managing the UCAT app — learning content, questions, students, and settings.

**Route:** `/ucat`

---

## Getting around

- Open **UCAT** in the Tutor Web sidebar.
- The dashboard shows the same areas as the sidebar, grouped into:
  - **Learn and practice** — Learning modules, Skill trainer
  - **Questions** — Questions, Sets, Mocks
  - **Students** — Students, Classes
  - **Settings** — Reconciliation, Question tags, Question stem categories, Sections
- Click a card (or the matching sidebar item) to open that area.

`[Screenshot: UCAT dashboard with the four card groups]`

---

## Access

- Only tutors with UCAT access can see these pages.
- If you don’t have access, you’ll see an access-denied message — ask an admin to enable UCAT for your account.
