# Follow sets-pool occupancy for UCAT set catalog identity

A set's student-facing catalog name and number follow whether a published, non-deleted mock currently occupies it, not mock ownership. Deleted and unpublished mocks keep their component sets for restore, but those published public sets already belong in the sets library; naming them as mock sections — including a blank mock number after the parent is deleted — contradicted that membership. Standalone identity, including a sets-pool number, is the consistent presentation until a published mock occupies the set again.
