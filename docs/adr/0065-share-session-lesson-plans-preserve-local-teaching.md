# Share Session lesson plans while preserving local teaching material

A future Session has one optional plan shared by its assigned Tutors, rather than a separate plan per Tutor. Matthew selected inline preparation in the existing Session dialog, using catalog files and standalone Topics; planning never becomes a prerequisite for submitting a Tutor log. When a Tutor opens the Session on a teaching iPad, newly planned resources are imported into that Tutor's local Teaching workspace without replacing pinned documents, annotations, ordering, or deliberate local removals. Standalone planned Topics remain preparation intent, and actual delivery still requires confirmation in the Tutor log. This provides a common preparation handoff while retaining the private, version-pinned teaching boundary in ADR-0062.
