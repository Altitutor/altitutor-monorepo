# Resolve current UCAT AI findings before publication

UCAT AI review remains optional and never blocks bulk import, but once a review produces a current manual-review flag, staff must resolve that finding before the stem can be published. This applies consistently to every stem publication path because showing unresolved findings while allowing an accidental publish would undermine the purpose of requesting staff judgment; staff retain final authority by accepting the proposed change or explicitly keeping, rejecting, or dismissing it.
