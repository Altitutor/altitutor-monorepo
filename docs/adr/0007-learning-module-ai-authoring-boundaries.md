# Learning module AI authoring boundaries

AI-assisted learning module authoring keeps lesson text and UCAT assessment content on their existing domain paths. Lesson text tools draft or rewrite rich-text blocks in the tutor's unsaved lesson draft, using lesson context and tutor intent, while AI-generated lesson question stems are still normal AI-generated question stems that must pass the tutor approval workflow before becoming student-visible. Accessible lessons may grant students access to approved private assessment content referenced by the lesson, but pending, rejected, or deleted assessment content is allowed only as a tutor-side placeholder in private drafts, because embedding separate lesson-only assessment content would bypass existing review, metadata, access, and reuse rules.
