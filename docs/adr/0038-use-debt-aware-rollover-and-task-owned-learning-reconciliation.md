# Use debt-aware rollover and task-owned learning reconciliation

Study-plan rollover waits until the next day that already contains planned work before marking earlier incomplete work skipped; through intervening rest days, the earlier work remains directly actionable as carry-over. Rollover does not move tasks or rebuild the future calendar. Missed non-optional Practice then creates capped section or category exposure debt for the next weekly or material-event generation; incomplete Learning modules remain eligible under their authored priority, Benchmarks remain governed by readiness and calibration policy, and optional work creates no debt. Weekly full generations are deterministically distributed across each Student's local day, while authenticated return may prioritise a genuinely stale plan.

Learning progress launched from a Study-plan task belongs exclusively to that task identifier. Progress started independently may reconcile only the earliest applicable active task for the module, and module completion skips other untouched future copies rather than falsely completing them. One activity satisfies at most one planned prescription: completing an exact Set or Mock early completes its matching task, while later duplicate prescriptions do not receive duplicate completion credit. Essential modules remain strongly prioritised while a section is in Learning but are not universal graduation gates when performance evidence or exam proximity establishes a later phase.
