# Agentic UCAT authoring tools

UCAT question-stem editing, learning module lesson authoring, generated-question review, and image adjustment use a chat-first agentic authoring surface built on a tool-loop protocol, replacing one-off AI action modals rather than preserving parallel legacy flows. The agent uses one shared chat shell with context-specific tool registries, executes ordinary draft edits as client-side tools against the unsaved editor state, feeds tool results back into the next model step, requires confirmation only for deleting whole units through chat tool cards, and shows a concise execution trace rather than raw reasoning; persistent generation and image upload remain server-backed, while examinable UCAT visuals prefer deterministic visual specs over raster image generation. Selected non-deterministic images and legacy SVG conversions use preview-first tool results in the existing chat, while retained Venn/set and Vega-Lite specs open direct editors; tutor-driven set-label placement may produce advisory warnings but is never blocked. This keeps tutor edits reversible through the existing Save/Discard boundary, reuses the UCAT model-profile, budget, usage logging, and prompt-layer stack, and avoids a separate agent configuration system while still supporting current-stem, learning-module lesson, selected-image, and generated-review batch scopes. A Codex-facing MCP server is an additional authoring client rather than a replacement for this embedded tutor-web surface, which remains available to tutors without Codex access.
