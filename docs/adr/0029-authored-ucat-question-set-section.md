# Question sets belong to an authored UCAT section

A UCAT question set belongs to exactly one UCAT section as an authored fact, required at create, including empty drafts. Member stems must be of that section; mixed-section sets are not a product. The set's section may change only while it has no member stems. A live set freezes its stems' section; deleted membership does not; restore re-asserts the match.

This rejects inferring the set's section from membership (first stem, majority, or earliest stem index), keeping mixed practice sets as a valid kind, and locking only the tutor-web add-stem sidebar. Those options left empty drafts without a section, produced three competing answers to "which section is this set?", and let the editor, student catalogue, and mock publication disagree.
