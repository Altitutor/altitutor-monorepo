# Index only published UCAT mocks

Mock catalog numbers are student-facing publication identity, like standalone set numbers. Draft and in-review mocks remain visible to tutors but are unnumbered and do not reserve a slot, so publishing the current public mocks yields `Mock 1` through `Mock N` instead of leaving holes for unpublished parents. Reorder, compaction, and restore follow that published-only sequence; attempt history still keeps the name captured when the attempt began.
