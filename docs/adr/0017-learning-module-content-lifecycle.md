# Learning module lessons share UCAT content lifecycle

Learning module **lessons** use the same authoring lifecycle (`draft` → `in_review` → `published`) and access scope (`public` / `private`) as question stems, sets, and mocks, instead of a single `is_private` flag. Existing public lessons migrate to published+public and existing private lessons to published+private so live student access is preserved. **Folders** stay catalog structure only (stored as published+public, no tutor lifecycle controls). Unpublished lessons may hold pending or non-published assessment refs; publishing requires published assessment blocks. Session links attach published lessons only and block unpublish/delete until removed. Stem withdrawal is blocked by learning-module attachments only when the embedding lesson is published.
