# Fast UCAT bulk capture and verified background repair

Bulk import optimises for durable capture: each candidate is imported as in review when it passes shared UCAT readiness gates, as draft when it does not, or omitted, without running AI review in the wizard. Deterministic duplicate analysis remains in the review step because it prevents avoidable catalog duplication without coupling ingestion to model latency: a duplicate warning defaults the affected stem to omit, opens a side-by-side preview, and remains overridable by the tutor. The durable background reviewer is the single AI-review workflow and may be requested for any saved stem, including drafts. It may atomically apply verified repairs to saved stems—including published stems—when bounded patch-specific verification proves the resulting content is better; uncertain changes remain staff suggestions. Initialising unset difficulty and time-burden metadata is a safe bounded repair, while existing tutor estimates are preserved. Every applied repair records exact before-and-after content in the shared recoverable UCAT content-change ledger, and the same run persists a current post-repair assessment instead of queuing a redundant full review.

This separates ingestion latency from review quality while accepting controlled autonomous writes in exchange for exact-revision concurrency checks, visible provenance, and safe reversal. UCAT readiness policy is shared by import, lifecycle transitions, and background assessment rather than duplicated by each workflow.
