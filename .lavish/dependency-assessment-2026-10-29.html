Migration costs to budget for

  • Next: async route props, removed next lint / eslint config, custom Webpack loaders and all five web builds.
  • Lint: flat configs; Next 16.4+ adapters cover web plugins. Expo lint needs its own check.
  • TypeScript: root baseUrl and workspace <7 rule block a blind TS7 update.
  • Shared UI: currently peers React18 / Next14; update types and test-library dependencies coherently.

Version gaps that can mislead

  • Root/marketing say ^5.8.3, but already lock TypeScript 5.9.3.
  • Web React says ^18.2, but locks 18.3.1.
  • Playwright manifests vary; all lock 1.56.1.
  • Native is already Expo 57, not 56 as the old plan says.

A newer release is a candidate, not proof of an exploitable vulnerability or a compatible upgrade.
