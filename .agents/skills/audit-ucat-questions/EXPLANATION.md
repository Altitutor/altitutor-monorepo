# Explanation teaching standard

An explanation must teach a student with little UCAT experience how to reproduce the solution. It shows the useful reasoning or representation, not only a restatement of why the stored answer is correct. Write it as if the student cannot see the keyed answer.

Load the core, the response-type block, and the section block that match this question.

## Core

A good explanation contains:

- what information to select
- how to represent or process it
- the shortest reliable method, including diagram(s) where they teach the method
- the necessary working
- the resulting answer
- useful warning(s) / gotchas when they would help the student improve

Write only that teaching. Leave out generic encouragement, advertising or links to unrelated lessons, other companies or platforms, editor-facing notes, a “Decoy Options” section, a restatement of the question, and a long method when a shorter reliable UCAT method exists.

## `multiple_choice`

One non-empty question-level `answerExplanation`. Also provide option-level explanations for a useful, identifiable mistake on that distractor. They must not repeat the question-level teaching.

## `drag_and_drop`

An explanation for every statement at option level. Each one states the answer, then shows why from the passage, a valid inference, or a counterexample. Add a question-level explanation only when it teaches a useful overall technique, without repeating the option explanations.

## Quantitative Reasoning

When the solution needs two or more meaningful operations, use an explicitly numbered method. For example:

1. Read the required values.
2. Calculate the relevant totals or changes.
   [calculation]
3. Apply the requested percentage, ratio or comparison.
   [calculation]
4. Match the result to the answer.

Give each step an action-oriented description. Keep closely related arithmetic in the same step.

Use exact arithmetic or a mental shortcut when faster; estimation when it safely identifies the answer; the calculator when it materially reduces time or error; as few calculator entries as practical.

State which values to enter into the calculator when that is useful. Mental arithmetic when that is clearly quicker.

## Decision Making

Teach the construction or elimination process, not a justification of the final answer after the fact.

Choose the representation that fits:

- ordered slots for sequencing
- an assignment table or elimination grid for matching
- a compact table for schedules
- a Venn/set diagram for set relationships
- branches or outcome tables for probability
- a counterexample for syllogistic conclusions

For ordering, assignment, and scheduling puzzles: introduce the representation; apply the most restrictive rule first; show how each useful rule changes the arrangement; update the slots or grid after meaningful deductions; then test or derive the answer.

Use incrementally filled diagrams (slot diagrams, matching diagrams, and the like) when they teach the method. A question solved more clearly in one short inference stays a short inference.

For evaluating-argument questions: state the criteria for a strong argument; apply them to the winning option; briefly name the decisive weakness in each other option.

For probability: define the relevant event or complement; show the setup; perform the shortest calculation; interpret the result in the wording of the question.

For venn diagrams: Identify the relevant shape(s)/region(s); perform calculation if relevant. Do not use set theory symbols

## Verbal Reasoning

Direct the student to the relevant paragraph or paragraphs. Identify the specific sentence, fact, contrast, or omission that decides the answer.

For True/False/Can't Tell, distinguish: directly supported; directly contradicted; not established by the passage.

Use only the passage. Paragraph numbers may appear in the explanation; they must not be labelled in the passage itself.

## Situational Judgement

Begin with the correct rating. Identify the central professional principle (patient safety, confidentiality, honesty, escalation, competence, teamwork). Explain how the proposed action affects that principle. When the distinction is close, explain why the neighbouring rating is too strong or too weak. Explain less appropriate alternatives only when that teaches a useful distinction.

## Skip advice

Mention skipping only for an exceptionally difficult or time-consuming question where attempting it under exam conditions would probably waste time. Ordinary hard questions get no skip line.
